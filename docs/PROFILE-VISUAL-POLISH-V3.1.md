# Profile Visual Polish v3.1

## Changes

- Compact language-composition card with no repeated internal title.
- Project cards now own true transparent rounded corners.
- README project gallery no longer uses a GitHub table, eliminating square cell borders.
- CHRONOS and The Quiet Ledger icons use accent-colour nodes instead of white dots.
- The complete Saturno icon family follows the same no-white-node policy in the separate v3.1 icon pack.

## Rendering contract

Project cards are PNG RGBA assets. All four corner alpha values must be zero.

The public README uses ordinary centered images rather than table cells because GitHub applies square borders to tables.
